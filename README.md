## 🛠️ Troubleshooting common issues

Most users get the software working on the first try. If you encounter errors, use these steps to fix common issues.

*   **Game refuses to start:** Check if you installed the correct version of the .NET Desktop Runtime. You can find this on the official Microsoft website.
*   **Mods do not load:** Verify the file path of your game. Ensure you placed the mod files directly into the Mods folder created by the installer.
*   **The loader shows an error icon:** Check your antivirus settings. Some security software prevents the loader from making necessary changes to game files. You may need to add an exception for your game folder.
*   **Game performance drops:** Too many mods can impact game speed. Disable specific mods one by one to find the one that causes the performance hit.
*   **Compatibility errors:** Ensure your game updates do not conflict with the loader version. Always look for the latest update on the release page if your game receives an official patch.

## 💡 Frequently asked questions

**Does this tool affect my game saves?**
No. This loader patches the game code but does not touch your save files. We still recommend you create a backup of your saves before you install mods.

**Can I use this for online games?**
Use caution with online games. Some titles have strong anti-cheat systems. Modding these games might trigger a ban. Only use mods in single-player modes unless the game developers explicitly allow them.

**How do I remove the loader?**
Run the installer again and select the Uninstall option. This removes the injection files and restores your game to its original state.

**Do I need programming knowledge?**
No. You do not need to read or write code. The installer handles all technical setup tasks for you.

## 📂 Organizing your files

The software creates two main folders in your game directory. 

*   **Mods folder:** This is where you put your downloaded mod files (.dll format). The loader reads this folder every time you launch the game.
*   **Plugins folder:** This folder handles advanced features that need to run before the game starts. Use this only if a specific mod tells you to do so.

Keep your folders tidy. Remove items you no longer use to ensure the loader functions efficiently.
